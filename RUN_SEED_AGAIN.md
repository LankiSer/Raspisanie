# Запуск seed скрипта снова

Скрипт теперь исправлен и проверяет существование данных перед созданием.

## Выполните:

```powershell
# 1. Скопировать исправленный seed.py в контейнер
docker cp backend/scripts/seed.py schedule_saas_backend:/app/scripts/seed.py

# 2. Запустить seed скрипт (он создаст только недостающие данные)
docker compose exec backend python3 scripts/seed.py
```

## Что изменилось:

✅ Скрипт теперь проверяет существование организации перед созданием
✅ Скрипт проверяет существование пользователей перед созданием
✅ Если пользователь уже существует - использует его
✅ Создает только недостающие данные

## После выполнения:

Все тестовые данные будут созданы:
- ✅ Пользователи (admin, methodist, teacher)
- ✅ Группы студентов
- ✅ Преподаватели
- ✅ Курсы
- ✅ Временные слоты
- ✅ Аудитории
- ✅ Зачисления на курсы
- ✅ Примеры занятий
