## 🔍 Валидные значения для unit

Согласно модели `Enrollment`, поле `unit` имеет тип `String(20)`.

Используемые значения:
- `"per_week"` - часов в неделю
- `"per_term"` - часов в семестр

Дефолтное значение в модели: `"per_week"`
