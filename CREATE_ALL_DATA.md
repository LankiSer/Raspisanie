# Создание всех тестовых данных

Пользователь создан, но остальные данные (группы, курсы, преподаватели и т.д.) не созданы.

## Решение

### 1. Скопировать исправленный seed.py в контейнер

```powershell
docker cp backend/scripts/seed.py schedule_saas_backend:/app/scripts/seed.py
```

### 2. Запустить seed скрипт

```powershell
docker compose exec backend python3 scripts/seed.py
```

Скрипт создаст:
- ✅ Организацию (если еще нет)
- ✅ Пользователей (admin, methodist, teacher)
- ✅ Учебный год и семестр
- ✅ Группы студентов
- ✅ Преподавателей
- ✅ Курсы
- ✅ Временные слоты
- ✅ Аудитории
- ✅ Зачисления на курсы
- ✅ Примеры занятий

## После выполнения

Все тестовые данные будут созданы, и вы сможете:
- Войти как admin: `admin@university.edu` / `admin123`
- Войти как методист: `methodist@university.edu` / `methodist123`
- Войти как преподаватель: `teacher1@university.edu` / `teacher123`

## Примечание

Если скрипт выдаст ошибку о дублировании данных (например, организация уже существует), это нормально - скрипт создаст только недостающие данные.
